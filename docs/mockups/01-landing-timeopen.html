WHY LEARNPATH

不是又一份
看起来很美、
然后吃灰的计划。

大多数 AI 计划在生成那一刻就结束了。这里多做了一步：每一道题的分数都会回到计划里，决定明天到底学什么。

01

骨架先行，再逐段细化

先让模型只输出「阶段名 + 天数 + 知识点」的短骨架并做校验，再按阶段单独细化。避免一次性生成超长计划，越往后质量越崩。

02

贴着 GitHub 仓库学

粘贴仓库链接，自动读目录与关键文件，切成学习章节：先讲清这段代码解决什么问题，再给代码走读任务与检查题，不是泛泛的知识点。

03

分数回写计划

掌握度按「正确率 × 新鲜度」衰减。低于阈值的知识点会自动加练、降难度；稳定通过的阶段直接跳过，复习间隔随理解程度拉长。

ONE LOOP, FOUR MOVES
STEP 01

说清目标

目标、截止时间、每周可投入、当前水平，可选补一个 GitHub 仓库。

STEP 02

生成与拆解

骨架 → 校验 → 逐阶段细化 → 落到每日任务与验收标准。

STEP 03

读、写、测

章节阅读支持批注与 AI 追问，测验按评分维度给分并解释扣分点。

STEP 04

回写与重排

得分进入掌握度模型，触发跳过 / 复习 / 加练，复习队列按间隔重复生成。
