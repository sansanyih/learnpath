## 2. 本地启动

```bash
# 后端
cd backend
python -m venv .venv
```

## 3. 后端约定

### 3.1 分层与依赖方向

```
api (路由/鉴权) → services (业务) → db/models
                      ↘ llm/ (仅 services 调用)
```

- 路由里不写业务逻辑，只做参数校验、鉴权、调用 service、返回 schema。
- service 方法第一个参数永远是 `user_id`（管理台除外，用 `admin_id`）。
- 不跨层直接调 ORM：路由不直接 `select`，service 不直接读 `Request`。

### 3.2 数据库

- 一律 async：`AsyncSession` 由 `Depends(get_db)` 注入。
- **不要在路由里手动 `commit`**：`get_db` 在请求成功时统一提交、异常时回滚。
- 批量写用 `db.add_all` + 一次 `flush`，避免 N 次往返。
- 时间统一用带时区的 UTC（`datetime.now(timezone.utc)`）；SQLite 下比较前先统一为 naive UTC，封装在 util。
- 除健康检查与统计 count 外，不写裸 SQL。

### 3.3 错误结构（M0 收尾实现）

```python
# 抛出
raise HTTPException(409, detail={"code": "EMAIL_TAKEN", "message": "这个邮箱已经注册过了"})

# 返回给前端统一为
{"error": {"code": "EMAIL_TAKEN", "message": "这个邮箱已经注册过了"}}
```

在 `main.py` 注册 `HTTPException` / `RequestValidationError` / 兜底三个 handler；`RequestValidationError` 映射为 `VALIDATION_ERROR`，兜底映射为 `INTERNAL_ERROR`（生产环境不泄露堆栈）。

### 3.4 Pydantic 与命名

- 请求模型 `XxxIn`，响应 `XxxOut`，内部管道 `XxxResult`。
- 所有响应模型显式声明，禁止直接返回 ORM 对象（除已配置 `from_attributes` 的 `UserOut` 这类简单结构）。
- 字段用 `snake_case`，前端 TS 类型保持一致（不做自动驼峰转换，减少心智负担）。

### 3.5 日志

- 标准 `logging`，格式：`%(asctime)s %(levelname)s %(name)s %(message)s`。
- M1 引入 `request_id`（中间件生成，响应头 `X-Request-Id`，日志与 LLM 调用带上）。
- 不打印密码、token、完整作答正文；LLM prompt 只打印长度与 hash。

## 4. 前端约定

- 目录：`api/ components/ composables/ design/ layouts/ router/ stores/ views/ types/`。
- **颜色/字体/间距只从 `design/tokens.css` 取**，组件里不出现十六进制色值。
- 状态：Pinia，一个领域一个 store（`session / plan / reader / quiz / review / ui`）。
- 网络：统一走 `api/request.ts`（注入 token、401 跳登录、错误结构解包）。
- 流式：统一用 `composables/useSSE.ts`（fetch + ReadableStream 解析），不在组件里手写解析。
- 路由：懒加载；`meta.auth` / `meta.admin` 由守卫处理。
- 组件命名：`PhaseTimeline.vue`、`TaskRow.vue` 这种"领域 + 角色"，不出现 `Item1.vue`。
- 文案：中文，短句；数字与单位之间加空格（`45 分钟`）。

### 4.1 落地页节奏与动效

- **一屏一节**：落地页每个区块外包 `.screen`（`min-height:100vh` + 垂直居中 + `scroll-snap-align:start`），`html.snap-landing` 上挂 `scroll-snap-type: y proximity`。新增区块必须包 `.screen`，否则会与相邻区块"杂糅"。
- **动效**：统一走 `v-reveal` 指令 + `src/design/motion.css`，只动 `opacity/transform`；首屏元素用 `delay` 错峰（0/80/140/220ms）。
- **可重播**：观察器在元素离开视口时移除 `is-visible`，再次进入（下滑或上滑）会重新播放；不要改成 `unobserve` 一次性。
- **降级**：`prefers-reduced-motion: reduce` 时自动关闭动画与吸附（`motion.css` / `landing.css` 里有对应媒体查询）。
- **截图验证**：动画截图要用 CDP 真实等待（`Emulation.setDeviceMetricsOverride` + `setTimeout`），不要用 `--virtual-time-budget`，否则会抓到动画未推进的中间态。

## 5. API 约定

| 项 | 约定 |
| --- | --- |
| 前缀 | `/api`（健康检查 `GET /health` 例外） |
| 鉴权 | `Authorization: Bearer <jwt>` |
| 成功 | 直接返回资源或 `{items,total,page,size}` |
| 失败 | `{"error":{"code","message"}}`，HTTP 状态码语义正确 |
| 分页 | `?page=1&size=20`，默认 20，上限 100 |
| 时间 | ISO 8601（UTC，带 `Z`） |
| 幂等 | 任务勾选、复习完成用 `PATCH`/幂等 `POST`，重复请求结果一致 |
| SSE | `text/event-stream`，事件见技术方案 §9.3；心跳 `: ping` 每 15s |
| 越权 | 一律 404（不返回 403，避免暴露资源存在） |

错误码前缀：`AUTH_*`、`VALIDATION_*`、`PLAN_*`、`REPO_*`、`QUIZ_*`、`LLM_*`、`ADMIN_*`、`INTERNAL_*`。

## 9. 联调流程

1. **先 mock 后真调用**：前端先用 mock SSE 开发；M1 再把 key 填进 `backend/.env`，用 `curl -N` 验证流。
2. **SSE 自测**：

```bash
curl -N -X POST http://127.0.0.1:8000/api/plans/stream \
  -H "Content-Type: application/json" \
  -d "{\"goal\":\"三个月掌握 FastAPI\",\"daily_minutes\":45}"
```

3. **跨域**：本地前端 `5173` → 后端 `8000` 走 Vite 代理，不依赖 CORS；线上 CORS 白名单只放 Vercel 域名与自定义域。
4. **数据库**：本地 SQLite 文件 `backend/dev.db`，删掉即重建；线上 Neon 不跑 `create_all`，用迁移脚本。
5. **示例数据**：`python -m app.db.seed_demo`（M4 实现）生成 3 份示例，游客入口依赖它。

## 10. 常见坑（遇到先看这里）

| 坑 | 现象 | 处理 |
| --- | --- | --- |
| bcrypt 与 passlib 版本冲突 | `AttributeError: module 'bcrypt' has no attribute '__about__'` | 直接用 `bcrypt`，不引 passlib |
| SQLite 时区 | aware/naive 比较报错 | 统一封装 `utcnow()`，比较前 `to_naive_utc()` |
| SSE 被代理缓冲 | 事件一次性到达 | 响应头 `X-Accel-Buffering: no` + `Cache-Control: no-cache` |
| CORS 带 credentials | 浏览器报 `*` 不允许 credentials | `allow_origins` 用白名单，不用 `*` |
| Neon 连接数 | 偶发 `too many connections` | 用 pooled 串，`pool_size=2~3`，避免每请求新连接 |
| HF 冷启动 | 首访 20–40s | 保活脚本 + 前端骨架屏 + 文案提示 |
| HF 磁盘不持久 | 重启后数据没了 | 数据全在 Neon；Space 内不落业务数据 |
| GitHub API 限流 | 60 次/小时 | 强制配 token；失败提示"稍后再试" |
| JSON 输出不稳 | 解析失败 | `json_object` + Pydantic + 带错误重试（≤2 次） |
