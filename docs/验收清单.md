## 2. 文档 API vs 实际实现

### 已对齐（本轮补）

| 文档 | 实际 |
| --- | --- |
| `POST /api/auth/logout` | ✅ token_version +1 |
| `POST /api/auth/change-password` | ✅ 校验旧密码 + token_version +1 |
| `GET /api/me/export` | ✅ 导出用户/计划/阶段/任务/掌握度/批注等 |
| `DELETE /api/me` | ✅ 软删 7 天，原密码登录可恢复 |
| `GET /api/plans/{id}/suggestions` | ✅ 返回 pending 调整建议 |
| `GET /api/reviews/due` | ✅ 别名到 `/api/review/queue` |
| `POST /api/reviews/{id}/complete` | ✅ 别名到 `/api/review/{id}/complete` |
| `GET/POST /api/notes` | ✅ 别名到 `/api/annotations` |
| `GET /api/dashboard` | ✅ `/api/stats`（连续学习/本周投入/复习策略） |
| `GET /api/demo/plan` | ✅ 预生成示例计划（公开） |

## 3. 本轮审计修复

1. **删除计划级联不完整**：补删 `chapter_progress`、`chapter_quizzes`、`chapter_quiz_attempts`、`chat_messages`（chapter/task scope）、`annotations`；新增测试断言全部为 0。
2. **对话历史取最旧 40 条**：改为「按时间倒序取 40 条再反转」。
3. **章节测验提交后状态条不刷新**：`onQuizSubmitted` 重新拉取章节状态。
4. **补 auth 生命周期**：logout / change-password（token_version+1，旧 token 立即失效）+ 测试。
5. **补文档承诺的别名端点**：`/api/reviews/due`、`/api/reviews/{id}/complete`、`/api/notes`、`/api/plans/{id}/suggestions`。
6. **测试**：27 → **33 passed**。
7. **任务覆盖修复**：阶段 12 天却只有 9 个任务；schema/prompt 改为「任务数 = 阶段天数，day_offset 0..days-1 每天一个」，严格校验 + 兜底；旧计划批量修复（4 份计划全部变为天数=任务数），新增 `audit_tasks.py`。
